# デザインルール

文字量の上限（箇条書きの数・本文と見出しの 1 行の幅・強調の数・表とコードの大きさ）は
`lint/slide-density.markdownlint-cli2.jsonc` にだけ書き、`scripts/lint_deck.sh` で確かめる。
ここには lint では確かめられない判断を書く。

## 用途

- **投影用**: 発表者が話しながら見せる。スライドには結論と短い要点だけを置き、説明はノートに書く
- **配布用**: 読み手が 1 人で読む。frontmatter に `class: handout` を書くと、文字が小さくなり、lint の上限が緩くなる

## 文字を減らす順序

lint の上限を超えたら、次の順で直す。
意味を運ぶ語は削らない（`writing-rules.md` の「短くするときに削ってよい語・削ってはいけない語」）。

1. 説明・補足・出典・数値の条件を、発表者ノート（`<!-- -->`）へ移す
2. スライドを分ける
3. 並列の要点は `cards`、比較は表、流れは図に置き換える

## 見出し

- 見出しはそのスライドの結論を言い切る文にする。「構成」「背景」のようなラベルにしない
- 見出しだけを順に読んで、話の筋が通るようにする

## 構成

- 表紙 → 目次 → （扉 → 本文）× 章 → まとめ
- 目次は章ごとに 1 行。まとめは目次と同じ順で、各章の結論を 1 行ずつ並べる
- 扉（`divider`）は章が 3 つ以上のときだけ置く
- 章ごとの枚数が大きく偏っていたら、章の分け方を見直す

## 色と強調

- アクセント色は、強調（`**`）・強調行・扉・目次の番号だけに使う。テーマが割り当てるので、デッキに `style:` を書かない
- 強調行: 表の先頭のセルを `**` で囲むと、その行に薄い背景が敷かれる。1 つの表で 1 行まで
- 表は罫線で囲まない（テーマが横線だけを引く）。要点のまとまりは `cards` の背景で示す

## レイアウト用クラス

| クラス      | 用途                              | 書き方                                                        |
| ----------- | --------------------------------- | ------------------------------------------------------------- |
| `title`     | 表紙                              | `#` タイトル、段落でサブタイトルと日付                        |
| `agenda`    | 目次                              | `## 目次` + 番号付きリスト                                    |
| `divider`   | 扉                                | 段落で章番号（`01`）+ `##` 章タイトル                         |
| `statement` | 1 文だけを大きく見せる            | 段落 1 つを改行で 2 行以内に分ける。`##` は小さいラベルになる |
| `cards`     | 並列の要点 2〜3 個                | 箇条書きの各項目の 1 行目がカードの見出し、2 行目が説明       |
| `handout`   | 配布用（frontmatter の `class:`） | 全スライドに効く                                              |

- 画像と文章の左右分割は `![bg right:45% contain](...)`。縦長・正方形の画像に使い、横長の図は `![center w:1000](...)` で全幅に置く
- スクリーンショットには `shot`（角丸と薄い影）を付ける: `![center shot w:900](...)`
- カードの見出しは 8 文字程度まで（カード幅で折り返すため）

## PNG の目視チェックリスト

lint が通った後に 1 回だけ見る。lint で分からないものだけを確認する。

- はみ出し・切れ（特に画像・コードブロック・表）
- スクリーンショットや図の中の文字が読めるか（読めなければ切り抜くか拡大する）
- カードの見出しやタイトルが変な位置で折り返していないか
- 章ごとの枚数の偏り、目次とまとめの対応
