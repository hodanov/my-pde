# 見た目のルール

証拠（図・グラフ・スクショ・表・コード）を置いたスライドでは、見出しを読んだ次に「見てほしい所」に目が行くようにする。
目安は、投影用なら 3 秒、配布用なら 1 回見て。
書き手は見てほしい所を知っているので、自分の図でそこに目が行くかを判断できない。
骨子で見てほしい所を 1 か所決め、下の 5 項目で作り、最後に `glance-test.md` で初見の人に見せる。

## 証拠の型を選ぶ

| 見せたいこと                 | 型                           | 書き方                                         |
| ---------------------------- | ---------------------------- | ---------------------------------------------- |
| 数字 1〜3 個                 | 大きな数字                   | `number` クラス。並べる数字の単位を揃える      |
| 項目の大小・順位             | 横棒（値の大きい順に並べる） | SVG（`assets/charts/bar.svg` を写す）          |
| 少ない期間の推移・前後の比較 | 棒（期間の順に並べる）       | SVG（同上）                                    |
| 仕組み・流れ・関係           | 図                           | SVG                                            |
| 画面の見た目・操作           | 切り抜いたスクショ           | `shot`                                         |
| 正確な値を引いて読ませる     | 表                           | 配布用向き。投影用は行数の上限が lint で厳しい |
| 並列の要点                   | カード                       | `cards` クラス                                 |

円グラフ・3D・2 軸のグラフは使わない。量の差が、角度や奥行きや軸の取り方で歪んで見える。

## 見て分かるかの 5 項目

| 項目       | 問い                                                                      | 前 → 後                                                                                  |
| ---------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 型         | 証拠の型が、見せたいことに合っているか                                    | 採用率 74% → 87% → 73% を表で並べる → 3 本の棒にして、8 月の棒だけアクセント色にする     |
| 1 か所     | 見てほしい所は 1 か所か。アクセント色はそこだけか。強調は値に付いているか | 表で「条件を足した後（8 月）」を強調する → 値の「87%」のセルを強調する                   |
| 近さ       | ラベルや数字は、指す対象の隣にあるか                                      | 凡例で色と名前を対応させる → 棒の横に名前と値を書く                                      |
| 余計なもの | 主張に関係ない色分け・枠・グリッド・UI の部品が残っていないか             | 構成図の箱を 4 色で塗り分ける → 箱は全部グレーにし、主張に関わる所だけアクセント色にする |
| 大きさ     | 画像の中の文字は、表示した大きさで読めるか                                | 2,380px の画面全体を 1,000px に縮める（文字は約 10px） → 必要な範囲だけを切り抜く        |

「1 か所」にする理由: 色・大きさ・囲みのどれか 1 つだけが周りと違う要素は、探さなくても目に入る。
違う所が 2 つ以上あると、どちらも浮かない。

「大きさ」は lint が確かめる。SVG は表示後の文字の大きさ、PNG は縮小率（表示幅 ÷ 画像の幅）を見る。
下限は `lint/slide-density.markdownlint-cli2.jsonc` にある。

## スクショ

- 画面全体を貼らない。見てほしい所を含む最小の範囲を切り抜き、lint の下限を満たす大きさで置く
- スライドと同じ明るさの配色（ライトテーマ）で撮る。暗い画面は、白いスライドの中で一番目立つ塊になる
- ブラウザの画面なら、要素だけを撮る（Chrome DevTools の「ノードのスクリーンショットをキャプチャ」など）と、切り抜きが要らない
- 見てほしい所が切り抜いた範囲の一部なら、アクセント色の枠で囲むか、画像の隣に見てほしい数字を大きく書く

切り抜きと枠は ImageMagick で付ける。座標は `幅x高さ+左+上`。枠の色は `clean.css` の `--accent` の値にする。

```bash
magick shot.png -crop 1200x500+40+180 +repage cropped.png
magick cropped.png -fill none -stroke '<--accent の値>' -strokewidth 6 -draw 'roundrectangle 820,20 1180,90 8,8' boxed.png
```

## 図とグラフ（SVG）

- 色は `assets/themes/clean.css` の `section` に並ぶ値だけを使う。アクセント色（`--accent`）は見てほしい要素だけに使い、ほかは `--surface` の箱と `--ink`・`--muted` の文字にする
- 色だけで区別しない。名前は要素の中か隣に書き、凡例は使わない
- 流れは左から右、上から下に置く
- viewBox の幅を表示幅と同じにして描く。そうすると、表示後の文字の大きさが `font-size` のままになる
- グラフは `assets/charts/bar.svg` を写して作る
  - 棒は 0 から始め、長さは「値 ÷ 最大値 × 520」で計算する
  - 見てほしい 1 本だけアクセント色にし、ほかは `--muted` を半透明（`fill-opacity="0.4"`）にする
  - 値は棒の端に書き、軸線・目盛り・グリッド・凡例は描かない

## 書き換え例

### スクショ → グラフ

- 前: 見出し「1 つの Skill だけ、ツール失敗率が 16.7% と高かった」の下に、ダッシュボードの 7 列の表のスクショを 1,000px に縮めて置く。
  文字は約 10px で、右端の列は切れている
- 後: ツール失敗率の列だけを、5 本の横棒にする。16.7% の Skill の棒と名前だけアクセント色にする（`assets/charts/bar.svg` がこの例）

### ラベルの強調 → 値の強調

- 前: 採用率の表で、「条件を足した後（8 月）」のセルを `**` で囲む。目に入るのはラベルで、値ではない
- 後: 「87%（30 件中 26 件）」のセルを `**` で囲む。87% がアクセント色になり、ほかの行は薄くなる。
  見出しの「87% に上がった」と、目に入る値が一致する

### 意味の無い色分け → 1 か所だけの色

- 前: 構成図の 6 つの箱を、橙・紫・青・緑で塗り分ける。色に意味が無いので、目が散る
- 後: 箱はすべて `--surface` にする。見出しが「受け口から Grafana までを、1 つのコンテナで動かす」なら、コンテナの枠だけをアクセント色にする
- 良い例: 見出し「人が手を動かすのは、採否のラベル付けとマージだけ」の流れ図で、人の箱 2 つだけをアクセント色にする。
  見出しの「人」と、色の付いた箱が対応する
