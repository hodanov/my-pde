# Tool selection

ファイルの探索・検索・読み取りでは、Bash より専用ツールを優先する。

- パスやファイル名の探索には Glob を使う。
- ファイル内容の検索には Grep を使う。
- 既知ファイルの読み取りには Read を使う。
- 独立した探索・検索・読み取りは、可能なら並列実行する。
- Bash は、ビルド、テスト、Git、生成処理などコマンド実行が必要な場合に使う。

探索・検索・読み取りだけを目的として、Bash で次のコマンドを実行しない。

- `cat`
- `find`
- `grep` / `rg`
- `ls`
- `head` / `tail`
- `sed -n`

パイプ、バイト表現、ツール固有の出力など、専用ツールでは確認できない場合は Bash を使ってよい。
ファイル操作のためだけに `cd` せず、専用ツールへ絶対パスを渡す。
